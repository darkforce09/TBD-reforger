# Map Raster Pipeline

Raster processing covers aerial orthophotos, satellite archives and containers, cartographic rendering, inland water, labels, and glyphs. Binary versions, numeric thresholds, image rounding, and output contracts are preserved by fixture tests.

Source modules: `aerial_orthophoto.rs`, `cartographic_rendering.rs`, `cli.rs`, `glyphs.rs`, `image_operations.rs`, `inland_water.rs`, `inland_water_archive.rs`, `map_label_archives.rs`, `map_labels.rs`, `mod.rs`, `satellite_archive.rs`, `satellite_archive_container.rs`.
