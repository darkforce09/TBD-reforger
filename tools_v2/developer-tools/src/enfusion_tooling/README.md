# Enfusion Tooling

The `enf` executable delegates source extraction, indexing, symbol scanning, API documentation, capability checks, and citation checks here. `mcp_broker.rs` owns the persistent Enfusion MCP broker used by `mcpd`.

Source modules: `apidoc.rs`, `capability.rs`, `carve.rs`, `citations.rs`, `cli.rs`, `index.rs`, `mcp_broker.rs`, `mod.rs`, `source.rs`, `symbols.rs`.
