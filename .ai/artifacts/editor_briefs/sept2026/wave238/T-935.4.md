  - crates/map-engine-core/src/dem/mod.rs declares png_decode only; no raw module.

  - aux.rs: emit dem/elevation.dem = TbdeHeader {width, height, scale_m, offset_m} + width x height u16 little-endian, holding the same values the PNG encodes.

  - One allocation: streamed bytes land in the final Vec<u16> (chunked LE decode); no RGBA, no f32 grid, no intermediate copies.

  - dem/raw.rs: TbdeHeader parse, LE decode into Vec<u16> (cast when aligned, chunked copy otherwise), lazy metre accessor; register `pub mod raw` in dem/mod.rs.
  - dem_load.rs: `load_dem(manifest)` picks raw when manifest.dem.raw is Some, else the existing PNG loader at mod.rs:619; register the module in world_assets/mod.rs.
