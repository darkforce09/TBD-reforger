## Findings

Findings are triaged FIX, NOTE or CLOSE; ids are `F-S7-NN`.

- **F-S7-01 (FIX, done by Q0b): editor slot ids were typed as the derived wire id.** The mission
  document keys its slot rows by the editor's own id (`slots[].uid`), yet `mission_document` and
  `mission_operations` typed those ids `SlotId` (`slots[].id`, recomputed on every compile), and
  `unit_symbology` declared its own copy. `orbat_slot_ids` now holds both types; the editor rows
  use `SlotUid`; `SlotId` stays only at `mission_model` `compiled/entities.rs:95` and
  `mission_compiler` `game_document/substitutions.rs:24,133`. Serialized bytes unchanged
  (`contract_parity_goldens`, `mission_review_binding`, the bare-string tests).
- **F-S7-02 (NOTE, operator): scratch test databases left on the local Postgres.** The API
  binaries need `TEST_DATABASE_URL`; Q0b created the base database `tbd_s7_q0b_it`, and the
  harness derived per-test databases from it. Nothing was dropped (deleting data is the
  operator's call).
- **F-S7-03 (FIX, X7): the foundation wording is stale.** `CLAUDE.md` §2 says foundation crates
  have no workspace dependency (`orbat_slot_ids` is tier 1 on `newtype_ids`), and
  `crates/foundation/README.md` says `newtype_ids` has no caller.
- **F-S7-04 (FIX, X7): two documents name streaming paths the split changed.**
  `legacy/map_engine/src/world/environment/buildings/README.md:17` names
  `WorldResidency::rebuild_buffers` (now `DrawBuffers::rebuild_buffers`);
  `documentation/crates/streaming/map_streaming.md:194` lists the two ticket-numbered test folders
  Q0a renamed by content. Reported by Q0a.
- **F-S7-05 (NOTE): open ticket T-1042 lists the two ticket-numbered test folders as open work**;
  they are now `buffers/tests/ingest_budget_and_building_toggle` and
  `buffers/tests/everon_glyphs_and_strips`. The ticket's owner updates it when it is taken up.
- **F-S7-06 (FIX, X7; known red until then): the rule-5 fixture test spells the editing tree's
  path.** `repository_laws` `engine_layers/tests/engine_layer_walls.rs`
  `a_browser_name_inside_the_engines_editing_tree_fails` plants `editing/tools/ruler/chain.rs` and
  expects `crates/mission_editing/map_editing_tools/src/ruler/chain.rs` in the law's output; relocate
  rewrites that expectation when Q3 moves the tools (no per-file exclusion exists), so the test
  fails from Q3 until X7 retires rule 5 and deletes it (A8).
- **F-S7-07 (NOTE, S11's relocation tool): relocate re-anchors `CARGO_MANIFEST_DIR` joins at the
  repository root when the destination crate has no `Cargo.toml` yet**, and a crate folder cannot
  get one earlier because an incomplete folder breaks the `crates/*/*` workspace glob. Q1 restored
  the three joins to `../../../assets/...` by hand (F-S4-10's family). Reported by Q1.
- **F-S7-08 (NOTE): `vegetation`'s public API still takes `String` chunk ids**, so
  `chunk_draw_buffers` keeps its vegetation-facing maps on `String`; retyping vegetation on
  `ChunkId` is its own change. Reported by Q1.
- **F-S7-09 (NOTE): `map_object_golden.rs` keeps its own raw-JSON join keyed by `f64` bits** (a
  golden comparison over the export's JSON, not a prefab map). Reported by Q1.
- **F-S7-10 (NOTE): a historical artifact spells the deleted feature.**
  `.ai/artifacts/engine_split_phase3a/01_original_full_3a_brief.md:114` is a frozen brief; the
  stage's `feature = "editing"` grep excludes `.ai/artifacts/`. Reported by X7a.
