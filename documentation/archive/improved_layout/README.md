# Improved layout proposals

The reorganization proposals for the website and the mod suite that preceded the workspace
restructure program, with the two planning anchors that stood in their code trees. Status:
archived — frozen records; the restructure program replaces them, and they quote the layout of
their time.

## Contents

```text
documentation/archive/improved_layout/
├── mod/                         the mod suite proposals: root layout, references, addons, scripts, roadmap
├── mod_code_tree_anchor.md      the planning anchor that stood in the mod suite's code tree
├── website/                     the website proposals: root layout, deploy, frontend, transport, API, engines
└── website_code_tree_anchor.md  the planning anchor that stood in the website's code tree
```

## How it works

Each proposal folder holds a master overview, one document per boundary and a phased roadmap;
each anchor summarised its proposal from inside the code tree it described. The restructure
research checked their claims against the checkout, and the restructure program carries what
held into its plan and target tree. A record here is never edited after it lands.
