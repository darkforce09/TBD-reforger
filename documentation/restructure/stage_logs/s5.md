  `contracts/definitions/mission-editor-payload.schema.json:62` and the code generated from it
  name a retired source path (a map-engine-core crate's mission wire-safety file); the scan now lives in the
  `mission_wire_safety` crate. The fix edits the schema description and regenerates the
  generated file (`cargo xtask ci schema-codegen`). Reported by W0.
- **F-S5-02 (CLOSE): `sha256sum -c` on an empty foreign baseline exits 1.** The worktree was clean
  at launch, so the baseline holds no lines and there is nothing foreign to protect; the brief
  now says to skip the check when the file is empty. Reported by W0.
- **F-S5-03 (FIX, done by D1a; tool defect NOTE for S4's relocate fix): the relocation tool
  re-anchored four `CARGO_MANIFEST_DIR` includes to a repository-root `/contracts/…`** after the
  crate move (the F-S4-10 signature); D1a fixed them to `/../../../contracts/…` by hand.

  pinned payload test path stale.** D1a removed the pin row and its fixture and updated two
  `verification_core` test expectations (allowed by A-S4b-hold, reported); the change rebases onto
  S4b's move of that crate to `tools/foundation/repository_laws`.
