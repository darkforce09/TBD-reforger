  archive records (`archives/{prefabs,roads,forest,water,blueprints}.rs`, `pod/instance.rs:47`), which
  the crate-anatomy law rejects (D2). Newtypes with byte-identical rkyv and serde forms, consumers
  switched. Reported by B5.

  (`apps/frontend/src/workspaces/editor/tests/t628_boot_progress.rs`) looks for `BootEvent::Budget`/`Done`
  in the moved `fetch.rs`; they now sit in the terrain host's `boot_byte_progress` adapter. The
  relocation rewrote the test's include path; its assertion is retargeted with the switch. Reported by B2b.
- **F-S4-03 (FIX, X4a): `render_primitives::text::layout::GlyphSpec.id` is a primitive `u32` id**
  (`text/layout.rs:19`), which crate-anatomy rejects; its constructor site is
  `me/overlay/symbology/text_packing.rs:40`. A glyph newtype with the switch. Also with the switch:
  `me/frame/tests/README.md:20` names the old damage test path, and `engine_boundary_rules.md:147`
  says "tested in the graphics engine" beside a `render_primitives` path. Reported by B4.
- **F-S4-04 (NOTE, B7 in S4b): engine rule 2 (no map nouns) scans only the graphics engine**, not
  `crates/graphics`, until B7 retargets it; `BuildingInstance` keeps its name until then (the
  birth kept public names). Reported by B4.

  two dependency-free crates, because the map engine's camera module is ungated and the API links
  the map engine at its default tier. S5 removes the API's map engine dependency. Reported by B3.
- **F-S4-06 (NOTE, relocation tool): several folder `path` rows into one destination folder nest the
  folders, and the tool's undo leaves files half-moved.** B3 restored them with `git mv` and used

  server control page doc (`server_control_page.md:217`). Reported by B6a.
