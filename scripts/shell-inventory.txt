#     process glue that must run before or without cargo (container entry, distrobox-host-exec
#     wrappers, git hooks); if that is genuinely what you wrote, add the line and the reviewer
#     will see it. Dropping the `.sh` off the name does NOT get you past the gate any more.

#     longer exists also fails, so this file cannot rot into a record nobody has checked.
