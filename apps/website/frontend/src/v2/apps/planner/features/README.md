# Mission Planner Features (`planner/features`)

## Capabilities
- **`drawing/`**: Freehand and geometric tactical graphics (arrows, circles, lines, boundaries).
- **`tasking/`**: Assigning specific squads (Alpha 1-1, Bravo 1-1) to tactical markers or rally points.
- **`radio_plan/`**: Displaying squad channel allocations directly on the map.
- **`export/`**: Exporting the plan as an image or tactical overlay for in-game briefing screens.
