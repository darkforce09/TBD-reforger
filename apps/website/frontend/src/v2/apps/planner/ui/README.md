# Mission Planner UI Shell (`planner/ui`)

## Layout Specification
- **Top Phase Bar:** Operational timeline selector (Phase 1: Infiltration, Phase 2: Assault, Phase 3: Exfil).
- **Floating Drawing Palette:** Tool selector for phase lines, breach arrows, boundary polygons, and tactical text notes.
- **Left Commander Drawer:** Slide-out panel for Commander's Intent, ROE (Rules of Engagement), and Squad Tasking cards.
- **Center Canvas:** Clean tactical whiteboard map.
