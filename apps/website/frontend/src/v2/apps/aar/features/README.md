# AAR Features (`aar/features`)

## Capabilities
- **`telemetry/`**: Deserializing server match logs and interpolating entity positions between tick snapshots.
- **`forensics/`**: Line-of-sight kill vectors (showing killer -> victim lines), engagement ranges, weapon statistics.
- **`heatmaps/`**: Movement and death density heatmaps overlaid on the terrain.
- **`event_log/`**: Searchable chronological event ticker.
