# Order of Battle & Outliner (`features/orbat`)

## Responsibilities
- Hierarchical structure: Side -> Faction -> Company -> Platoon -> Squad -> Fireteam -> Slot.
- Virtualized Outliner tree view mounted in `ui/left`.
- Drag-and-drop reparenting and slot reordering.
- Slot census summary (e.g., "120 on Everon — BLUFOR 60 v OPFOR 60").
- Leader slot designation and vehicle crew assignments.
