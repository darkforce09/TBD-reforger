# Bottom Status Bar (`ui/bottom/`)

## Purpose
Displays readouts and telemetry along the bottom edge of the screen.

## Hosted Readouts
- **Coordinates:** World X/Y (metric) and 6/8-figure MGRS grid coordinates.
- **Elevation:** Ground elevation in meters ASL at current cursor position.
- **Zoom Level:** Viewport scale percentage.
- **Performance HUD:** Render frame time and WebGPU device status.
