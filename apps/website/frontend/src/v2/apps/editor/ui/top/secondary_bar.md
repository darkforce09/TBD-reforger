# Secondary Toolbar (Row 2)

## Purpose
Hosts the Eden toolbelt (relocated from the bottom pill), coordinate snapping toggles, and canvas interaction modes.

## Mounted Slots
```text
[ Select | Move | Rotate | Ruler | LOS | Place ]  |  [ Snap Grid ] [ Snap Terrain ]  |  [ Cam Speed ]
```
- **Active Tools:** Tool selection buttons from `features/manipulation`, `features/assisting_tools`, and `features/placement`.
- **Snapping Controls:** Grid and elevation snap toggles.
- **Camera Controls:** Camera movement speed dropdown (1x, 2x, 5x, 10x).
