# Primary Top Bar (Row 1)

## Purpose
Displays top-level mission identity, global menus, quick environment controls, and system actions.

## Mounted Slots
```text
[ File | Edit | View | Mission | Help ]  ---  [ Mission Title ] [ Save Status ]  ---  [ Scrubber ] [ Weather ]  ---  [ Settings ]
```
- **Menu Bar:** Dropdowns from `features/mission` and global editor commands.
- **Mission Identity:** Editable name and clean/dirty/saving status indicator from `features/mission`.
- **Quick Environment:** Quick time-of-day slider and weather preset from `features/environment`.
- **Settings Trigger:** Gear icon that opens the settings modal.
