# Hub 3: Mission Hub (`src/v2/pages/mission_hub`)

Central repository for community scenarios and editor launchpad.

## Pages
1. **`library/` (`/missions`)**: Searchable catalog of scenarios (replaces `editor/library/mission_library.rs`).
2. **`overview/` (`/missions/:id`)**: Detailed scenario dossier with launch editor trigger (replaces `mission_overview.rs`).
3. **`create_dialog/`**: New scenario wizard modal.
