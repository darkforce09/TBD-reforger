# Platform Frame Layout Specification

## Screen Regions
1. **Sidebar Navigation (Desktop):** Persistent 240px drawer on the left displaying the 6 command hubs.
2. **Top Navigation Bar:** Breadcrumbs, live server status indicator, notification bell, user profile avatar / login button.
3. **Main Content Canvas:** Scrollable `<main>` container hosting the active page route.
4. **Mobile Navigation Drawer:** Collapsible slide-out menu for screen widths < 1024px.
