# Vehicle Database (`/vehicles`)

## Architecture
- **`page.rs`**: Main layout file.
- **`faction_filter.rs`**: Faction selector (US Armed Forces, Soviet Army, FIA).
- **`vehicle_grid.rs`**: Vehicle cards with 3D render thumbnails.
- **`spec_drawer.rs`**: Slide-out panel with detailed armor values, seating, top speed, and inventory capacity.
