# Pure Tactical Algorithms (`map_engine/tools`)

Pure mathematical algorithms without UI components:
- **`ruler.rs`**: 2D/3D Euclidean distance, azimuth/bearing calculation, elevation delta profiles.
- **`los.rs`**: Ray-terrain intersection algorithm, viewshed horizon scanner.
- **`mortar.rs`**: High/low angle ballistic trajectory solver, elevation/deflection tables.
- **`symbology.rs`**: NATO APP-6 / MIL-STD-2525 symbology vector rendering primitives.
