# UI/Mock

Static mock datasets for offline UI development, screen styling, and layout verification.

### Roles & Responsibilities
- `TBD_LobbyMockData.c`: Provides comprehensive mock ORBAT hierarchies, factions, squads, roles, and loadout specs mirroring Stitch design mockups.
- `TBD_MissionSelectorData.c`: Supplies mock terrain lists and mission catalog entries for standalone scenario browser testing.

### Call Flow & Contracts
Standalone data repositories consumed solely by UI controllers when developing screens without active network or server dependencies.
