# UI/layouts/Session/PostGame

Post-match layouts for victory outcomes and after-action debriefing.

## Layouts

- **`TBD_EndScreen.layout`:** Fullscreen victory / defeat banner overlay triggered on match conclusion. Displays winner badge, match end condition, duration, and transition timer to debrief.
- **`TBD_DebriefScreen.layout`:** After-action review (AAR) scoreboard layout presenting team scores, casualty breakdown, objective timeline, and spectator navigation controls.
