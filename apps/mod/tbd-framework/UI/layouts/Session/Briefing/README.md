# UI/layouts/Session/Briefing

Tactical briefing screen and briefing tab layout templates.

## Layouts

- **`TBD_BriefingScreen.layout`:** Map-centric tactical briefing screen inheriting vanilla `Map.layout`. Provides fullscreen map integration with overlay docks for briefing navigation.
- *(Upcoming Sub-Panels)*:
  - `TBD_PrimaryNav.layout`: Top-level tab switcher (Map / Briefing / Players / Markers).
  - `TBD_BriefingNav.layout`: Secondary category index (Situation, Mission, Execution, Administration, Command & Signals).
  - `Panels/`: Frequencies, ORBAT, FriendlyAssets, EnemyAssets, FriendlyUniforms, EnemyUniforms, Objectives, Rules, Lore, Parameters.
