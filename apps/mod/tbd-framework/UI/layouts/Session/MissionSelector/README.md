# UI/layouts/Session/MissionSelector

Scenario browser layouts for browsing, filtering, and voting on missions across terrains.

## Layouts

- **`TBD_MissionSelector.layout`:** Fullscreen scenario browser layout featuring search/filter inputs, terrain list view, scenario grid, and scenario details modal.
- **`TBD_TerrainRow.layout`:** List row layout for the left-hand terrain browser (terrain thumbnail, name, scenario count).
- **`TBD_MissionCard.layout`:** Grid card layout displaying scenario thumbnail, title, author, recommended player count, game mode tags, and selection state.
