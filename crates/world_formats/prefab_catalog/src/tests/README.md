# prefab_catalog/tests

Unit tests of the prefab rows and their archive, the footprint lookups, the prefab tables of both
served forms, and the render classes.

## Contents

- `footprint_lookups_tests.rs`
- `prefab_rows_tests.rs`
- `prefab_tables_tests.rs`
- `render_classes_tests.rs`

## Boundaries

Run with `cargo test -p prefab_catalog`; the Everon cases read `assets/terrains/everon/objects/`.
