# After-Action Review (AAR) Workspace (`website/frontend/apps/aar/`)

The AAR application replays server telemetry logs over the 2D map terrain, enabling forensic post-match analysis of operations.

## Features
- Multi-channel timeline scrubber with variable playback speeds (1x, 2x, 5x, 10x).
- Player positioning, movement traces, engagement lines, and ballistic casualty markers.
- Objective capture history and combat event log synchronization.
