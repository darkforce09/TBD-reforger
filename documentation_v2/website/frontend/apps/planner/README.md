# Tactical Planner Workspace (`website/frontend/apps/planner/`)

The Tactical Planner is an interactive briefing and operational whiteboard application for squad leaders and mission commanders.

## Features
- 2D map canvas with real-time collaborative markup.
- NATO MIL-STD-2525 tactical graphic placement (phase lines, objectives, boundaries, ingress/egress routes).
- Briefing slide synchronizer and squad assignment dossier.
