# Standard Platform Pages (`website/frontend/pages/`)

Domain-driven frontend pages for standard platform navigation, community operations, scenario catalog, administration, and tactical utilities.

## Directory Atlas
- `navigation/`: Topbar and persistent navigation drawer.
- `account/`: User login, Discord OAuth callback, and settings.
- `command_center/`: Operational dashboard, server telemetry, and announcements.
- `operations/`: Operations calendar, briefing dossier, slotting, deployments, leaderboards.
- `mission_hub/`: Scenario library catalog, overview dossier, create modal.
- `field_tools/`: Tactical utilities including the mortar ballistics calculator.
- `doctrine_and_info/`: Doctrine wiki, vehicle catalog, and modpack distribution manifests.
- `administration/`: Administrative command panels (event manager, server control, personnel, approvals, content manager, audit logs).
