# Enfusion Mod Suite (`mod/`)

Documentation for the Enfusion engine mod suite, mirroring `apps/mod/`.

## Subsystem Architecture
- `tbd_framework/`: Shipping gameplay framework mod (`TBD_Framework`) containing game mode controllers, phase management, safe-start, radios, loadout enforcement, and tactical HUD widgets.
- `tbd_export/`: Workbench export tooling addon (`TBD_Export`) extracting terrain elevation, road networks, building voxel geometry, and asset registries.
- `tbd_emcp/`: Enfusion MCP automation bridge (`TBD_EMCP`) exposing 19 NetAPI automation handlers for programmatic Workbench manipulation.

## Code Mapping
- `apps/mod/tbd-framework/`
- `apps/mod/tbd-export/`
- `apps/mod/tbd-emcp/`
