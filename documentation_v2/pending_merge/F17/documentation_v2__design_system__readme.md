# Design System & Symbology (`design_system/`)

Authoritative specifications for platform UI design tokens and tactical military symbology.

## Specifications
- `design_tokens.md`: Single dark theme `#0d1322`, Aegis color palette, typography scale, spacing rules, and animation invariants.
- `military_symbology.md`: NATO MIL-STD-2525 / APP-6 military symbology standards and in-game tactical marker subsystem.
