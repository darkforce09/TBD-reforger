# Standalone CAD Workspaces (`website/frontend/apps/`)

High-performance, standalone interactive CAD applications built on top of the graphics and map engines.

## Applications
- `editor/`: 2D/3D Scenario Creator CAD workspace shell, toolbelt, and Arsenal / Loadout Forge.
- `planner/`: Tactical whiteboard and operational briefing interface.
- `aar/`: After-Action Review (AAR) telemetry replay player.
- `debug/`: Engine diagnostics testbenches (building occlusion and world line-of-sight probes).
