# Enfusion UI Layouts & Widget Hierarchy (`mod/tbd_framework/ui_layouts/`)

Specifications, layout hierarchies, and visual references for in-game Enfusion widgets (`.layout`).

## Layout Subsystems
- `Common/`: Reusable design primitives (buttons, panels, cards, modal sheets).
- `Hud/`: In-game tactical HUD, compass tape, safe-start banner, capture zone timers.
- `Session/`: Pre-game lobby, interactive slotting tree, tactical briefing dock, pause menu.
- `ui_references/`: 13 UI specification documents and 35 reference screenshots.
- `ui_stitch_mockup/`: 88 Stitch interactive mockup files (43 panels).

## Code Mapping
- Layouts: `apps/mod/tbd-framework/UI/layouts/`
