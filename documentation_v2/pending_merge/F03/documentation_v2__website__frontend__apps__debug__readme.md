# Diagnostics & Testbenches (`website/frontend/apps/debug/`)

Diagnostic CAD workspaces for inspecting raw engine computations, occlusion boundaries, and terrain features.

## Testbenches
- Building Occlusion Viewer: 3D building voxel mesh and slab occlusion testbench.
- World Line-of-Sight (LOS) Diagnostic: Raymarched terrain and vegetation line-of-sight elevation probe.
