# Navigation & Permissions Registry

Defines the structure of the sidebar navigation:
- **Command Center:** Dashboard (`/`), Server Intel (`/server-intel`), Announcements (`/announcements`)
- **Operations:** Schedule (`/events`)
- **Mission Hub:** Mission Library (`/missions`)
- **Field Tools:** Mortar Calculator (`/tools/mortar`)
- **Doctrine:** Wiki (`/wiki`), Vehicles (`/vehicles`), Modpacks (`/modpacks`)
- **Administration:** Events (`/admin/events`), Servers (`/admin/server`), Personnel (`/admin/personnel`), Approvals (`/admin/approvals`), Content (`/admin/content`), Audit (`/admin/audit`)
