# UI Design System Primitives (`website/frontend/core/ui/`)

Reusable component primitives conforming to the Aegis Tactical design system.

## Components
- Buttons, text inputs, search inputs, dropdowns, checkboxes, segmented controls.
- Modal dialogs, slide-over sheets, toast notifications.
- Visual tokens, color palettes, and glassmorphism styling definitions (`aegis.css`).
- Colocated visual reference tokens in `visual_reference/`.

## Code Mapping
- Source: `apps/website/frontend/src/v2/core/ui/`
- Styles: `apps/website/frontend/style/aegis.css`
