# Workbench Export Tooling (`mod/tbd_export/`)

Enfusion Workbench export plugin suite extracting world terrain, infrastructure, and entity catalogs for ingestion by the website engines.

## Export Plugins
- `TBD_TerrainExportPlugin`: 16-bit DEM elevation raster extraction.
- `TBD_RoadsExportPlugin`: Vector road network topology, splines, and road surface classifications.
- `TBD_BuildingsExportPlugin`: 3D building collision meshes, voxel bounding boxes, floor slab slices.
- `TBD_RegistryItemsExportPlugin`: Weapon, magazine, vehicle, and uniform catalog schemas.
