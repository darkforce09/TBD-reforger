# T-935.15 — Plan

## Context
Chunking bounds parse cost. T-935.1–.3 made the world payload POD and load it through
`bytemuck::cast_slice`, so decode is effectively free and the reason for splitting the world into
`objects/chunks/{cx}_{cy}.bin` no longer exists. What remains is the cost chunking adds: a boundary
crossing triggers fetch, decode, upload and eviction, which is the pan/zoom stutter.

Operator decision 2026-09-07: delete it. The pattern was inherited from a fifteen-year-old game
engine and is not a 2026 method.

## Approach
1. Measure the before: full-width pan with `?t9382=1` (T-938.2's counter), record allocations and
   frame spikes per boundary crossing.
2. Copy the shape that already works — T-935.10's satellite is one TBDS container + rkyv index +
   range fetch (`tbd_sat.rs` header/index, `satellite.rs:170-184` `fetch_index_head`). Do not invent
   a second container shape.
3. Emit container + spatial index in `build.rs` beside the existing chunks; prove the object set is
   byte-equivalent before deleting anything.
4. Cut the loader over to range fetches; then delete the chunk emit; then delete `residency.rs` and
   `chunk_bin.rs`.
5. Perturbation: reintroduce a per-chunk fetch on the pan path → the zero-allocation pan test goes
   red; restore, `touch`, green.

## Risks
- **Adaptation instead of deletion.** The failure mode is keeping a chunk concept alive under a new
  name. `residency.rs` and `chunk_bin.rs` must go, not shrink.
- `residency.rs` is file-length allowlisted and 290 chunk references; `map-engine-core` needs
  `--all-features` or the `world` module is cfg-gated out and tests pass vacuously.
- The occluder (`occluder/trace.rs`) and density ladder both walk the chunk grid; they need the
  index, and their goldens must not be widened to absorb a different traversal order.
- Sixteen files carry chunk vocabulary. **This is a program, not a slice** — split before dispatch.

## Verification
- `cargo test -p map-engine-core --all-features`; `cargo test -p website-frontend`
- `cargo xtask mk leptos-gates`
- A full-width pan reports zero residency allocations, measured with the same counter as step 1.
