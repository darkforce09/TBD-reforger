# T-090.12.3 — WorldOccluder: TLAS, chunk DDA, compounds, world-los CLI

## Context

`CompoundBuilding`'s instance loop is a linear scan with a per-instance slab reject — the TLAS-leaf math, unaccelerated — and nothing walks chunks. A triangle BVH over 12-tri boxes misses an observer standing inside a box, so the TLAS must be a dedicated AABB tree.

## Approach

`crates/map-engine-core/src/world/occluder/{mod,tlas,placed,dda,trace}.rs` (each < 600 lines) + `occluder_tests.rs`: `AabbTlas::candidates` by slab test ordered by entry `t`; 2-D Amanatides–Woo over 512 m cells; rows placed by `Rigid::from_enfusion([x, z_up, y_north], [pitch, yaw, roll], scale)`; expanded prefabs trace through `trace_parts` / `reduce_events` extracted from `building_compound_los.rs` (compound delegates, pins unchanged); un-expanded prefabs fall back to a proxy box with `Fidelity::Proxy`; `Coverage` names missing chunks and pending BLAS; BLAS cache capped at 48 MB; `blocked_fn` drops into `wash_band`. `WorldResidency` gains `chunk`, `prefab_rows`, `take_residency_events`. `cargo xtask map world-los --census/--probe/--bench`.

## Risks

Frame mix-ups (map y = north vs engine z): pinned by a placed-tree test and `map_to_engine`. Memory for a 2 km disc (≈ 30 MB rows + TLAS worst case) reported by `memory_bytes`.

## Verification

`cargo test -p map-engine-core --all-features` (TLAS ≡ brute force incl. observer-inside, DDA ≡ rasteriser, placement, proxy → exact promotion, missing chunk, doors, `blocked ≡ verdict != Clear`, farmhouse door-parity replay after placement 3983/4000, wash over two chunks, cap eviction); `cargo test -p xtask`; clippy `-D warnings`; `world-los --bench` numbers in the commit body.
