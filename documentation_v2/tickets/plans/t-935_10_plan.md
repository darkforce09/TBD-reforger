# T-935.10 — Plan

## Context
`tools/tbd-tools/src/map/unified.rs` writes the TBDS v1 container (everon-sat.tbd-sat, 152 MB,
14 mips); `tbd_sat.rs` parses its hand-packed tile table via HTTP Range. v2 keeps the payload
layout and replaces the table with a validated rkyv index.

## Approach
1. `unified.rs`: `--container-version 2` (default): header {TBDS, version 2, index_len} + rkyv
   TbdSatIndexV2 + tiles; v1 writer retained behind `--container-version 1`.
2. `tbd_sat.rs`: Range-read the first 64 KB, dispatch on version; v2 index via `access_checked`;
   v1 decoder untouched; shared tile Range math.
3. Round-trip test with a 3-mip synthetic container in both versions; perturbation writes
   `index_len` one byte short → red.

## Risks
- Index larger than 64 KB for deep mip chains: read `index_len` from the fixed header and issue
  a second Range request when needed.
