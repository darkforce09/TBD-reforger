# T-090.11.1 — SurfaceKind, sidecar v2, multi-hit BVH traversal

## Context

Every sidecar triangle is opaque today; glass and foliage need a per-triangle class and a traversal that can continue past non-terminal surfaces.

## Approach

In `crates/map-engine-core/src/bvh.rs`: `SurfaceKind {Opaque=0, Glass=1, Foliage=2}`; `BvhSidecar.kinds`; sidecar version 2 = v1 layout + `kinds` (ntris × u8, zero-padded to 4 B) with header reserved word 0 as flags; `parse` accepts v1 and v2, `emit_bytes` writes v2; `any_hit_where` / `first_hit_where` (terminal predicate) and `all_hits`; `any_hit` / `first_hit` become wrappers. Tests in `bvh_tests.rs`. xtask `bvh-emit` writes v2; re-emit the farmhouse sidecar + golden.

## Risks

Byte-level drift in the golden — re-bless deliberately with old → new sizes in the commit body; the 400/400 pins must not move.

## Verification

`cargo test -p map-engine-core --all-features`; `cargo test -p xtask` (both farmhouse pins 400/400 phantom 0, shape (3170, 4012, 1521)).
