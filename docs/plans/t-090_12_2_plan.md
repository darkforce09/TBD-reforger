# T-090.12.2 — BLAS library: --all-prefabs, descriptors, manifest

## Context

`bvh-batch` takes one `--prefab` per call; 85 BLAS exist for one building. The occluder needs a collision BLAS (or an explicit `blocks:false`) for every one of the 1,623 prefabs, fetchable by pid.

## Approach

`xtask/src/map_blueprint/library.rs`: loop over `prefabs.json.gz` (strip the `{GUID}` prefix), resolve through `PrefabResolver`, walk with the T-090.11.2 `Walker` (root mesh as an `InstanceKind::Shell` record at identity; buildings add doors / frames / panes / furniture), dedup BLAS by XOB stem, emit `prefabs/descriptors/<pid>.json`, `prefabs/blas/*.bvh`, deterministic `prefabs/blas-manifest.json` with the top-100 hot set. Shared `PrefabDescriptor` / `BlasManifest` types in core `world/occluder/descriptor.rs`; schemas; `cargo xtask verify blas-manifest`. `--dry-run` census first (tree foliage coverage, no-COLL by kind, bytes); `hull.rs` (visual-LOD0 convex hull tagged Foliage) if any tree lacks foliage triangles.

## Risks

Library size ≈ 40 MB estimated: plain git if ≤ 24 MB measured, else LFS with the CI selective pull extended so the verify lane still runs. Prefabs whose `.et` chain fails to resolve are `blocks:false` with a reason, never phantom-blocking.

## Verification

`cargo test -p xtask` (descriptor/manifest round-trip, no-COLL → `blocks:false`, stem dedup, determinism, farmhouse descriptor = T-090.11 instance set); `cargo xtask verify blas-manifest`; `cargo xtask ci schema-validate`; per-kind table, total bytes and the 20 largest in the commit body.
