# T-090.11 — Architectural interiors: SurfaceKind BVH, portals, glazing, props

## Context

T-090.6 shipped shell-only BVH line-of-sight (400/400 parity, phantom 0). Doors, window frames, glass panes and furniture are separate Enfusion entities slotted onto XOB socket bones, so the shell mesh cannot see them and every triangle is opaque. The viewer draws buildings on borrowed terrain lanes. Operator plan approved 2026-09-03; the debug viewer is the integration surface (mission-editor integration is a follow-on).

## Approach

Six sequential slices, one commit each on `main`: (1) `SurfaceKind` + sidecar v2 + filtered/multi-hit traversal in `crates/map-engine-core/src/bvh.rs`; (2) offline pipeline in `xtask/src/map_blueprint` (PAC1 pak reader, `.et` resolver, XOB node/socket table + COLL subrange → game material, `bvh-batch` emitting per-XOB BLAS + `<slug>.instances.json`); (3) Workbench oracle (recon children + door-inclusive parity) validating socket transforms; (4) `building_compound.rs` — instances under rigid transforms, hinge `DoorState`, glass/foliage walk, wash over instances, `TriSource`/`SegClass` drawing; (5) dedicated `Interior*` / `SceneVegetation` / `InteriorProbe` render lanes in `draw_order.rs`; (6) viewer bench (`building_interior.rs`, door click-to-toggle, glass rays, `?scene=1` trees).

## Risks

XOB node-record layout is undocumented — the recon dump is the oracle and the fallback placement source. Tree COLL may lack foliage colliders — visual-LOD hull canopy fallback. Workbench may be unavailable — script changes still land and the two missing fixtures are reported, never silently dropped. Lane count (13) follows the fill/outline-twin precedent.

## Verification

Per slice: `cargo test -p map-engine-core --all-features`, `cargo test -p xtask`, `cargo test -p website-frontend`, `cargo test -p map-engine-render`, clippy `-D warnings` (core all-features, render wasm32, frontend wasm32 --all-targets), `cargo xtask verify file-length`, `cargo xtask ticket check`, trunk release build. Pins: shell parity 400/400 phantom 0 every slice; door-inclusive parity ≥ 395/400 phantom 0 once the fixture exists; live viewer checks in the T-090.11.6 commit body.
