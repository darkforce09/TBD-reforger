# T-946.24 — Plan

## Context

The wave-242 verifier broke `mirror_lockstep` four ways within an hour of it landing, including one
BLOCKER that reintroduced the exact defect class the guard was written to close. All four are
silent failures, which is why they are worth fixing immediately rather than filing.

## Approach

1. `EXPORT_ONLY_SCRIPTS` — the 13 scripts that legitimately have no framework twin, so any other
   export-only script is a lost framework file and fails.
2. `mirror_normalise` — a literal-aware comment stripper that KEEPS literals and folds the
   punctuation the ASCII rule forces, replacing the borrowed code stripper.
3. `MIRROR_DIVERGENT_ASSETS` — the three shared non-script paths that must differ, with reasons;
   every other shared non-script path is compared byte-for-byte.
4. Walk all of `Scripts`, not just `Scripts/Game`.
5. Fix `strip_enfusion_comments_and_strings` for the unread-field counter that still uses it.
6. Missing directory is an error, not an empty pass.

## Risks

Comparing literals could fail on punctuation the fold does not cover. That is deliberate: an
unfolded character produces a "make the two copies agree" message rather than a silent pass. The
fold list is explicit and small, and one real drift surfaced on the first run.

## Verification

Re-run the verifier's four attacks; each must fail the gate naming the path. Clean tree passes.
