# Design System
## Overview
A dark, data-dense tactical interface for the TBD Reforger Event Platform.
Designed for PC gaming community admins and milsim operators to orchestrate complex operations.
Focuses on clear hierarchy, high data density, unmistakable primary actions, and tactical telemetry.

## Color Roles & Contrast
- **Primary** (`#3b82f6`): Interactive CTAs, active states, key submissions (Publish Mission, Link Account, Submit Code).
- **Secondary** (`#1f2937`): Cards, containers, panels, and secondary toolbars.
- **Surface / Background** (`#0b1120` / `#0d1322`): Deep tactical navy-black background.
- **On-Surface** (`#ffffff`): Crisp high-contrast typography.
- **Card Accent / Borders** (`#38bdf8` / `#424754`): Subtle 1px borders and active highlights.
- **Error / Destructive** (`#f87171`): Validation errors, lethal status, out-of-bounds alerts.
