# Design System
## Overview
A dark, data-dense interface for the TBD Reforger Event Platform.
Designed for PC gaming community admins to orchestrate complex operations.
Focuses on clear hierarchy and unmistakable primary actions.
## Colors
- **Primary** (#3b82f6): CTAs, active states, key interactive elements
- **Secondary** (#1f2937): Supporting UI, cards, panels
- **Surface** (#0b1120): Page backgrounds
- **On-surface** (#ffffff): Primary text on dark backgrounds
- **Error** (#f87171): Validation errors, destructive actions
## Typography
- **Headlines**: Inter, bold
- **Body**: Inter, regular, 16px
- **Labels**: Inter, medium, 14px
## Components
- **Buttons**: Rounded (6px), primary uses brand blue fill, secondary uses outlined styles
- **Inputs**: Dark background matching the elevated theme, subtle borders, white text
- **Cards**: Background relies on `#1f2937`, 1px solid border `#38bdf8`, 4px border radius
## Do's and Don'ts
- Do use the primary color sparingly for major submissions (e.g., Publish Mission, Submit Code).
- Don't use bright white (#ffffff) for large background areas.
- Do maintain clear visual states for Unassigned vs. Assigned slots.
